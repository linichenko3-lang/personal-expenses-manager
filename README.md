# Personal Expenses Manager

Навчальний Python-проєкт для обліку особистих фінансів. Репозиторій
об'єднує консольну версію Expense Tracker, Django-застосунок із REST API
та навчальні приклади роботи з базами даних, SQL і тестуванням.

## Можливості

### Консольний Expense Tracker

-   облік доходів і витрат;
-   перегляд транзакцій та балансу;
-   робота з категоріями й бюджетами;
-   формування звітів;
-   збереження даних.

### Django-застосунок і REST API

-   керування транзакціями, категоріями та бюджетами;
-   автентифікація користувачів;
-   JWT-авторизація API;
-   обмеження доступу до чужих транзакцій;
-   фільтрація транзакцій за типом;
-   перегляд статистики;
-   документація API через Swagger.

### Навчальні матеріали

-   приклади Python, SQL і CRUD-операцій;
-   робота з базами даних;
-   автоматизовані тести;
-   колекція Postman для перевірки API.

## Технології

-   **Python** --- основна мова програмування.
-   **uv** --- керування залежностями та середовищем.
-   **SQLite** --- локальна база даних.
-   **Django** --- вебфреймворк.
-   **Django REST Framework** --- створення REST API.
-   **Simple JWT** --- JWT-автентифікація API.
-   **drf-spectacular** --- OpenAPI-схема та Swagger UI.
-   **Postman** --- ручне тестування API.
-   **pytest, Django TestCase, DRF APITestCase** --- автоматизоване
    тестування.

## Встановлення

### 1. Клонування репозиторію

``` bash
git clone <URL-репозиторію>
cd personal-expenses-manager
```

### 2. Встановлення залежностей

Виконуйте команди з кореневої папки репозиторію:

``` bash
uv sync
```

Команда встановлює залежності, визначені в `pyproject.toml` та
`uv.lock`.

Якщо `uv` ще не встановлено, скористайтеся офіційною інструкцією:
https://docs.astral.sh/uv/

### 3. Налаштування середовища

Якщо застосунок потребує змінних середовища, створіть локальний файл
`.env` і заповніть потрібні значення. Не додавайте до Git паролі,
секретні ключі або токени.

## Запуск

Команди нижче потрібно виконувати з кореневої папки репозиторію.

### Консольний Expense Tracker

``` bash
uv run python main.py
```

### Django-застосунок

Застосувати міграції:

``` bash
uv run python django_app/manage.py migrate
```

Запустити сервер розробки:

``` bash
uv run python django_app/manage.py runserver
```

Після запуску:

-   Сайт: http://127.0.0.1:8000/
-   Swagger UI: http://127.0.0.1:8000/api/docs/
-   OpenAPI schema: http://127.0.0.1:8000/api/schema/

Для зупинки сервера натисніть `Ctrl + C` у терміналі.

## REST API

Основні маршрути Django REST API:

  -----------------------------------------------------------------------------------------------
  Метод                   Endpoint                                        Призначення
  ----------------------- ----------------------------------------------- -----------------------
  GET, POST               `/api/transactions/`                            Перегляд і створення
                                                                          транзакцій

  GET, PUT, PATCH, DELETE `/api/transactions/{id}/`                       Перегляд, редагування
                                                                          та видалення транзакції

  GET                     `/api/transactions/?transaction_type=income`    Фільтрація доходів

  GET                     `/api/transactions/?transaction_type=expense`   Фільтрація витрат

  GET                     `/api/transactions/statistics/`                 Статистика транзакцій

  GET                     `/api/categories/`                              Перегляд категорій

  GET, POST               `/api/budgets/`                                 Перегляд і створення
                                                                          бюджетів

  POST                    `/api/token/`                                   Отримання JWT-токенів

  POST                    `/api/token/refresh/`                           Оновлення access-токена
  -----------------------------------------------------------------------------------------------

Повний перелік операцій доступний у Swagger UI.

## Postman

Колекція запитів для тестування REST API зберігається в папці
`postman/`.

Очікувана назва файлу:

``` text
postman/postman_collection_transactions.json
```

Імпортуйте JSON-файл у Postman, налаштуйте адресу сервера та тестові
облікові дані, після чого виконуйте запити до запущеного Django API.

Перед публікацією репозиторію перевірте, що в колекції немає реальних
паролів і токенів.

## Безпека

-   `.env` призначений для локальних налаштувань і не повинен потрапляти
    до Git.
-   Не публікуйте паролі, токени та інші облікові дані.
-   Для доступу до захищених API-маршрутів потрібен JWT access-токен.
